# Loan Approval Prediction

A beginner machine-learning project that predicts a loan status using a Random Forest Classifier.

## Files
- `app.py` — Streamlit web application
- `loan_model.pkl` — trained Random Forest model
- `train_model.py` — script to retrain the model
- `train_u6lujuX_CVtuZ9i.csv` — training dataset
- `requirements.txt` — Python dependencies

## Run locally
1. Install Python.
2. Open a terminal in this project folder.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Start the app:

   `streamlit run app.py`

## Deploy online
1. Upload the project files to a GitHub repository.
2. Open https://share.streamlit.io/
3. Sign in with GitHub and choose **Create app**.
4. Select the repository, branch, and `app.py`.
5. Click **Deploy**.

This is an educational prediction demo, not a real financial decision system.
